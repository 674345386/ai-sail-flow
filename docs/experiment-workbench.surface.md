# 视频创作实验台界面约定

范围：`/lab` 与创作 Agent 内的实验台标签。模式：Operate。

使用者需要从目标开始，由 Agent 组织工作，再在需要时编辑某一步、检查结果、换方法和保留成功流程。沿用深色对话区与浅色画布的既有分区。

首屏：先选已有创意或明确新建。空空间默认进入路线提案，显示“让灵感，先做一次实验”，引导用户在对话中描述目标和添加素材。顶部用紧凑工具栏整合视图切换、完成状态、新建方案与当前实验深度；设置中保留 Native、探索、研究三档滑杆、执行方式和运行环境，更多操作中提供制作路径、Skill 导入与配方。探索合并原探索与实验能力。执行方式中保留自动选一条 / 用户选择、每次最多路线数。旧实验档兼容为探索，旧研究档保持最高档，历史提案与执行快照不重写。执行画布保留六种可选规划起点。

路线提案以目标为起点，先显示原始输入，理解与约束可展开；按实现机制分组，模型与工具变体作为组内提案卡。每张卡突出预期效果、做法、可开始 / 待补素材 / 待准备环境 / 待核实 / 暂不可用状态，步骤、提示词、条件和方法来源渐进展开。选择上限来自提案时的设置；用户勾选后一次提交，创建独立执行方案并交给 Agent 顺序执行。未补齐条件的路线提供准备工作草稿入口。

Native 自动采用一条已就绪推荐路线；其他档位默认在提案后等待用户选择。方法树是选择关系，选定后才转换为含真实输入依赖的执行图。路线提案和执行画布通过页内切换保留，底部固定显示选择与执行入口。窄面板将滑杆与路线卡堆叠。

交互重点：方案有明确目标，并逻辑组织步骤与独立产物；画布位置保持自由。方案切换、详情与比较共用第二行，不再常驻目标说明；方案详情汇总目标、步骤、当前方法和产物。桌面端两行工具栏约 84px，设置与更多操作浮层展开，不挤占执行画布；窄面板允许工具栏换行。顶部切换方案会突出相关节点。

每个步骤保存多种备选方法，各自包含完整提示词、输入参考图、上游节点、模型和参数。整套备选方案复制制作路径，步骤内的备选方法只替换该步做法。每次执行保存来源快照与独立产物，历史结果保留；方案与方法均可并排比较、采用真实产物。改变已采用结果后，相关下游提示更新。

旧实验台数据自动补齐方案、方法与执行来源，不改变节点位置和媒体文件。配方保存方案结构与方法，复用时重置结果与素材引用。界面由持久化领域数据驱动。

局部颜色使用低饱和绿作为实验台工作状态与操作色，延续既有 Agent 绿色语义。白色节点、12px 节点圆角、7px 常规控件圆角；状态色仅区分正在执行、失败和过期。工具界面使用系统中文无衬线字体，10–14px 控件、15–17px 节点与面板标题。

未验证：尚未进行浏览器视觉验收，按用户要求未使用 browser / computer use。没有第三方渲染 Skill 的完整真实制作验收。
