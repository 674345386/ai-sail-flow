# 视频创作实验台界面约定

范围：`/lab` 与创作 Agent 内的实验台标签。模式：Operate。

使用者需要从目标开始，由 Agent 组织工作，再在需要时编辑某一步、检查结果、换方法和保留成功流程。执行画布遵循用户提供的 Liblib 画布截图：炭黑点阵底、媒体直接呈现在画布上、标题在节点外侧、圆形连接点与平滑连线。路线提案保留原有阅读界面。

首屏：先选已有创意或明确新建。空空间默认进入路线提案，显示“让灵感，先做一次实验”，引导用户在对话中描述目标和添加素材。顶部用紧凑工具栏整合视图切换、完成状态、新建方案与当前实验深度；设置中保留 Native、探索、研究三档滑杆、执行方式和运行环境，更多操作中提供制作路径、Skill 导入与配方。探索合并原探索与实验能力。执行方式中保留自动选一条 / 用户选择、每次最多路线数。旧实验档兼容为探索，旧研究档保持最高档，历史提案与执行快照不重写。执行画布保留六种可选规划起点。

路线提案以目标为起点，先显示原始输入，理解与约束可展开；按实现机制分组，模型与工具变体作为组内提案卡。每张卡突出预期效果、做法、可开始 / 待补素材 / 待准备环境 / 待核实 / 暂不可用状态，步骤、提示词、条件和方法来源渐进展开。选择上限来自提案时的设置；用户勾选后一次提交，创建独立执行方案并交给 Agent 顺序执行。未补齐条件的路线提供准备工作草稿入口。

Native 自动采用一条已就绪推荐路线；其他档位默认在提案后等待用户选择。方法树是选择关系，选定后才转换为含真实输入依赖的执行图。路线提案和执行画布通过页内切换保留，底部固定显示选择与执行入口。窄面板将滑杆与路线卡堆叠。

交互重点：方案有明确目标，并逻辑组织步骤与独立产物；画布位置保持自由。方案切换、详情与比较共用第二行，不再常驻目标说明；方案详情汇总目标、步骤、当前方法和产物。桌面端两行工具栏约 84px，设置与更多操作浮层展开，不挤占执行画布；窄面板允许工具栏换行。顶部切换方案会突出相关节点。

每个步骤保存多种备选方法，各自包含完整提示词、输入参考图、上游节点、模型和参数。整套备选方案复制制作路径，步骤内的备选方法只替换该步做法。每次执行保存来源快照与独立产物，历史结果保留；方案与方法均可并排比较、采用真实产物。改变已采用结果后，相关下游提示更新。

旧实验台数据自动补齐方案、方法与执行来源，不改变节点位置和媒体文件。配方保存方案结构与方法，复用时重置结果与素材引用。界面由持久化领域数据驱动。

执行画布局部使用 `#191919` 背景、22px 间隔的 `#414141` 点阵、`#252525` 节点表面、`#e7e7e7` 主文字和 `#a3a3a3` 辅助文字。第二版图片与视频优先按真实媒体比例展示；空产物按已保存的生成比例展示。初始宽度按横图、竖图、方图分别取 320、220、266px，可在选中时等比例缩放到 160–720px，并保存显示尺寸；尺寸调整不改变语义版本，不触发下游失效。媒体使用 12px 圆角、完整显示；名称在框外上方，来源与版本在下方，次要信息在悬停、聚焦或选中时显示，运行、失败与失效状态保持可见。空产物节点显示真实等待状态，备选方案与已有原方案结果的区别继续保留。选中轮廓为浅灰白，平滑贝塞尔连线在选中或运行时使用 `#9acbf5`，失效和错误继续以文字及独立状态色说明。

底部中央工具条仅常驻添加、选择、平移、适应画布与更多；制作路径、Skill、配方、整理与导出放入更多菜单。缩放与可切换小地图独立放置，小地图默认关闭。框选后整组拖动保存全部移动节点的位置。现有坐标不自动重排；显式点击整理后使用实际测量的节点尺寸，列间距 124px、行间距 74px；未取得尺寸时保留默认 390 × 340px 排列。

选中步骤或尚未生成的结果时，打开可拖动、收起、关闭的浮动创作面板。面板包含 Prompt、参考图、模型、比例、图片质量或视频时长与清晰度。模型来自当前服务状态；输入 @、点击素材列表、拖入已完成图片或上传 JPG/PNG/WebP 均可添加参考。草稿按创意与方法在本机缓存，保存写回原方法；检测到外部修改时先提示冲突。点击生成先保存并校验参数，再交给现有 Agent 执行入口。新草稿仍按当前实验深度与用户选路规则提案；禁止因添加节点、拖图或选中节点而自动生成。

节点右侧 + 可点击打开上下文菜单，也可拖动连接已有步骤。菜单提供继续创作图片、制作视频、备选做法、比较、连接已有步骤。新创作原子创建方案、步骤与结果占位，继承上游输入与可用图片引用。完成产物仅提供继续创作与来源查看，不将历史结果直接改成方法编辑器。选中节点突出上下游并弱化无关节点。比较入口复用既有方案/方法比较抽屉；尚未提供画布内并排分组。

双击媒体或点击放大按钮可进入大图/视频预览，关闭后保留原画布视口。节点详情和执行记录按需浮出，不改变画布宽度。窄容器中创作面板适应可用宽度与高度，拖动边界随容器变化重新约束。

操作与完成状态保留 Agent 的低饱和绿色语义。节点与面板编辑、方案比较、方法编辑、真实媒体预览、依赖连接、执行和保存机制不变。深色样式仅作用于 `.lab-media-canvas`，普通二创画布与路线提案不继承此主题。

验证边界：第二版通过类型检查、生产构建与 `scripts/experiment-canvas-v2-check.ts` 的领域逻辑及服务端组件渲染检查。尚未进行浏览器视觉和指针交互验收，按用户要求未使用 browser / computer use；未触发付费媒体生成。参考来自用户截图，未下载或解析 Liblib 私有项目页面。逐项复盘和第三版优先级见 [第二版复盘](experiment-canvas-v2-review.md)。
# 按尝试轮次显示输入与输出

执行画布保持 Operate 模式，直接用现有执行记录与当前方法生成轮次内的视图实例。每轮的输入素材分别成节点，连接本轮输出；下一轮即使引用相同素材，也显示新的输入节点，底层文件与引用保持共用。提示词、参考图顺序、模型和参数沿用执行快照，通过输出节点的参数入口查看。

轮次实例的坐标、宽度和比例只缓存在浏览器本地，不增加服务端数据结构。首次进入定位一轮，新增执行与产物不再自动缩小全图；顶部轮次按钮定位相应输入输出，显式整理按轮次重新排布。完整依赖图保留在更多菜单中。

输出的「再试一次」从所选执行快照创建新做法，原有输入与结果保留；新执行再次获得独立的输入节点。连接新素材只能修改待执行的一轮。没有新增付费生成行为，实际执行继续使用已有的保存、选路和生成入口。
