# 视频创作实验台界面约定

范围：`/lab` 与创作 Agent 内的实验台标签。模式：Operate。

使用者需要从目标开始，由 Agent 组织工作，再在需要时编辑某一步、检查结果、换方法和保留成功流程。沿用深色对话区与浅色画布的既有分区。

首屏：先选已有创意或明确新建；空实验图直接提供六种真实的规划起点，避免模拟完成结果。画布首屏显示制作节点、输入关系和状态，可适应整个流程。

交互重点：方案有明确目标，并逻辑组织步骤与独立产物；画布位置保持自由。顶部切换方案会突出相关节点，方案详情汇总目标、步骤、当前方法和产物。

每个步骤保存多种备选方法，各自包含完整提示词、输入参考图、上游节点、模型和参数。整套备选方案复制制作路径，步骤内的备选方法只替换该步做法。每次执行保存来源快照与独立产物，历史结果保留；方案与方法均可并排比较、采用真实产物。改变已采用结果后，相关下游提示更新。

旧实验台数据自动补齐方案、方法与执行来源，不改变节点位置和媒体文件。配方保存方案结构与方法，复用时重置结果与素材引用。界面由持久化领域数据驱动。

局部颜色使用低饱和绿作为实验台工作状态与操作色，延续既有 Agent 绿色语义。白色节点、12px 节点圆角、7px 常规控件圆角；状态色仅区分正在执行、失败和过期。工具界面使用系统中文无衬线字体，10–14px 控件、15–17px 节点与面板标题。

未验证：尚未进行浏览器视觉验收，按用户要求未使用 browser / computer use。没有第三方渲染 Skill 的完整真实制作验收。
