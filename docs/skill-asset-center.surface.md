# Skill 资产中心

范围：Agent Mode 右侧“资产中心”、新建创意中的 Skill 选择、实验台的参考现场与运行环境。模式：Operate。

沿用现有浅色实验画布、深色创作外壳、系统中文字体和低饱和绿色操作语义。列表优先呈现用途、主题、验证状态；选中后依次查看实验现场、官方报告、运行环境、原文。窄工作区使用列表与详情切换，依据容器宽度适配。

主操作是“基于此实验创作”；没有实验时使用“采用 Skill”。收藏固定版本，新建创意可多选。创作方法先保存到个人空间，用户明确选择后发布到公共中心。公开内容包含所选方案的 Prompt、输入输出、源文件和环境；凭据由采用者单独绑定。

参考现场是不可变的证据。采用时恢复源文件并复制可编辑步骤；执行状态和输出槽位重新开始。原例子通过固定引用按需读取，不随每次对话重复传输。实际环境与参考环境分开，改变依赖会使受影响步骤需要重新执行，历史运行保留原来的环境快照。

所有外部收录和社区发布都使用 `sail-skill-v1` 协议，由独立的官方验证创意运行。报告核对声明、实际输出、复现样本及环境完整性；无执行则无分数。置信区间显示真实样本量。同一执行只算一个样本；继承的旧输出不能作为新验证的通过证据。原文属于待验证资料。

交付 ZIP 包含 SKILL.md、manifest.json、environment.json、源文件、依赖锁、参考实验 JSON 与真实素材。每个包固定资产版本和来源 commit，模型远程别名标记为动态版本。LivePortrait 初始为待验证的来源登记，采用时先读取并固定来源；没有虚构 Demo 或评分。

公开收录、发布和分享会自动发起官方验证；同版本已有报告或任务时不会重复执行。第一版同时保留手动复测和上游更新检查；RSI 自动发现与周期调度留待后续接入。数据沿用本机文件持久化。托管环境的程序化执行继续遵守既有独立执行器限制。

已做类型检查、本地真实代码执行与 API 检查。按用户要求未使用 browser / computer use，尚未进行浏览器视觉验收；未安装或实跑 LivePortrait 的 GPU 推理环境。
