# 三阶段统一画布结构稿

桌面布局：项目导航 / 300px 阶段操作栏 / 弹性画布；顶部保留项目路径和账户操作。画布采用浅色点阵，三阶段由左向右连接。阶段栏展示编号、状态、摘要及主要操作，点击定位画布；窄屏可收起操作栏。

节点：参考视频与产品资料、视频拆解与分析结果、镜头证据或分镜网格、人物参考与校正、提示词、生成结果。节点使用白色底、细边框、低对比阴影和清晰的状态；运行与错误显示在所属节点。素材与生成结果由项目数据驱动。

详细素材表单、逐镜头编辑、时间线和媒体选择以弹窗或既有抽屉打开。画布沿用已有二创节点布局与项目级保存，支持拖动、缩放、适应画布和重置。原有阶段地址定位到相应区域。
