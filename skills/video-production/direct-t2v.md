# 端到端文本直出（T2V）

## 1. 适用与不适用边界
- **适用**：单镜头氛围片、自然/城市空镜 B-roll、快速验证创意方向、无需严格锁定固定角色或商品外观的短片（4–10 秒）。
- **不适用**：多镜头连续剧情、需要严格保持固定主角人脸/服装或特定电商商品细节的成片（应改用 `asset-keyframe-i2v` 或 `ingredients-r2v`）。

## 2. 前置资产与输入检查
- 无需强制上传图片或视频，但需明确画幅比例（如 `16:9` / `9:16`）、目标时长与视觉风格。
- 若用户已提供参考图或参考视频，请勿降级为纯 T2V，应优先选用带视觉锚点的 Skill。

## 3. 标准画布拓扑与底层工具映射
1. `asset`（创作意图）→ 2. `step`（视频直出，`tool: "generate_video"` 或 `"generate_minimax_video"`）→ 3. `artifact`（生成成片）。
- 仅在探索/对比模式需要不同风格时，通过多条并行路线（Route A/B）或 `branch-method` 生成对照，避免无授权重复付费。

## 4. Prompt 编译规范
- 采用六要素紧凑结构：**主体 + 明确动作 + 场景与光影 + 镜头语言（景别/运镜） + 质感风格 + 音效/节奏**。
- 多镜头原生直出时，用清晰的时间分段描述（如 `0–3s ...；3–6s ...`），每段只安排 1 个主动作与 1 种运镜，避免镜头过多导致画面崩坏。
- 贴近用户原意，不堆砌无意义的画质套话。

## 5. 质检与降级策略
- 若直出视频出现主体漂移、构图偏差或运动失控，优先切换为 `asset-keyframe-i2v`（先出一张确认好的静态关键帧，再 I2V），而不是在纯 T2V 上反复盲抽。
