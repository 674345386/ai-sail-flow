# AI-Sail Flow

面向跨境电商内容团队的本机工作台。流程：**上传素材 → 视频拆解 → 产品与市场改写 → 选择成片模式 → 生成或导出**。

## 项目与创意

当前默认一个「我的工作空间」，工作空间下有多个项目，每个项目可创建多个创意。例如「夏装」项目下创建「色卡夏装换装上」「青少年夏装」两个创意。项目负责归类；参考视频、产品资料、分析、Prompt、生成任务与成片都独立保存在各自创意中。

左侧「项目」旁的加号创建项目，项目行的加号在该项目下创建创意；展开项目后切换创意。顶部路径显示「我的工作空间 → 项目 → 创意」；点击项目名可重命名，点击创意名可修改名称和所属项目。归档与恢复作用于单个创意。

原有创意自动归入「默认项目」，保留原 ID、素材与制作结果，可通过编辑所属项目整理。项目分类保存在 `data/workspace-projects/`；为兼容原有制作接口，创意记录仍保存在 `data/projects/`，现有 `/api/projects/:id` 制作接口继续使用创意 ID。

导出包的 `manifest.json` 升为版本 2，分别记录 `workspaceId`、`projectId`（所属项目）和 `creativeId`（制作内容）。

## 运行

需要 Node.js 22.12+（推荐 24）、npm、FFmpeg / ffprobe。本机配音与字幕模式还需要 macOS 的 `say` 与 `swift`。

首页提供 **自动工作流** 和 **手动工作流** 两个入口，共用同一份项目资料、分镜、Prompt 和执行记录。新建创意时也可选择入口；原有项目默认保留手动方式。

工作台顶部提供同级的 **步骤视图 / 画布视图** 切换，两种视图共享项目草稿和执行状态。画布默认铺满工作区，连接四个步骤及对应产物；点击节点后，左侧展开该步骤的素材、镜头、产品与市场或交付表单，点击画布空白处、关闭按钮或按 Escape 可收起。点击视频、图片、分镜、提示词包或成片可打开浮窗预览；选中镜头后可定位原片对照。节点支持拖动，画布支持平移、缩放、适应全图和恢复布局，并按项目在浏览器中记住布局。画布工具栏也可展开或收起当前节点表单。自动模式可以在画布中设置成片方式、音色和分辨率，运行中查看进度或接管编辑；旧版步骤工作台继续保留。

- 自动工作流先收集参考视频、产品事实、市场语言和成片方式。点击开始后，服务端连续执行拆解、改写、文生视频、配音字幕或保留原声的拼接，交付最终 MP4。开始时设置本次最多新生成的片段数；达到上限会暂停，恢复已有上游任务不占新请求数。
- 「查看制作步骤」打开只读工作台，「查看输入与输出」打开过程画布，自动任务继续执行。「接管并编辑」等待当前任务完成后停止后续步骤；再切换自动方式并点击继续，会复用仍有效的结果。手动编辑的 Veo Prompt 保存到项目，自动模式直接使用该原文。
- 执行在本机服务端完成，离开页面仍可继续。服务重启会保留结果并暂停流程，等待用户继续。失败时停止推进；已取得 Veo 任务 ID 的片段恢复原任务。没有任务 ID 时，继续按钮明确提示重新提交。不会自动反复重新生成失败片段。
- 自动生成默认使用 t2v，产品图片参与分析和改写；i2v、r2v 继续在手动工作台配置。声音字幕方式与自动/手动工作流相互独立。
- 自动和手动工作台均可按项目编辑「保持什么 / 允许改变什么」。这份通用复刻要求会进入 Gemini 改写和可预览的 Veo 分镜 JSON；参考分析提供原片的场景、人物角色、动作、运镜与节奏依据。当前 Veo 接入仅有文字和图片生成输入，不提供原视频到视频的局部替换；文生视频不能保证逐帧复刻或只改指定区域，页面会在生成前说明。

```sh
npm install
npm run dev
```

访问 <http://127.0.0.1:4317>。默认只监听本机，不暴露到局域网或公网。

首次启动前，在本机 `.env` 配置独立 Supabase 项目的前端变量：

```sh
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

## 网络与接入渠道

用 `npm run dev` / `npm start` 启动：两个脚本都带 `NODE_USE_ENV_PROXY=1`。Node 的全局 fetch 默认忽略 `HTTPS_PROXY`，直接 `tsx server/index.ts` 起服务会绕过本机代理，Google 直连超时约 10.5 秒、兼容接口被劫持成 404，界面上看到的却是「模型连接失败」或「渠道未提供 gemini-3.8-flash」。

「兼容接口地址」按 OpenAI 协议填 base URL，例如 `https://maiai.ai/v1`。裸域名、`/v1beta` 这类版本根，或整条 `.../v1/chat/completions` 也接受，服务端归一化成同一个 endpoint。

Veo 3.1 视频生成使用独立的 `SOP_VEO_API_KEY`（或模型设置中的 Veo Key），固定请求 `https://gaorui.cc/v1/videos`，不复用 Gemini / maiai.ai 密钥。文生视频使用 `veo_3_1` 且不传 `images`；首尾帧图生视频使用 `veo_3_1-fl`，传 1–2 张图片 URL（首帧、可选尾帧）；参考图生视频使用 `veo_3_1-components`，传至少 1 张图片 URL。三种模式均发送提示词、`resolution`（`720p` / `1080p` / `lite`）、`aspect_ratio`（`9:16` / `16:9`），固定输出 8 秒，不发送 `duration`。图片必须是公网 HTTPS 直链；本机产品图不会自动上传或公开。任务提交后按 ID 轮询，完成后下载到本机。若下载失败但上游任务 ID 已取得，可在交付页恢复同一任务，不会再次提交付费生成。[Veo 3.1 接口文档](https://gaoruitech.apifox.cn/doc-8981138)。

默认视频拆解使用 Gemini 3.8 Flash Agentic Video Understanding：沿用原来的 `.../v1beta/models/gemini-3.8-flash:generateContent` 中转地址，在视频 Part 上发送 `media_processing: "AGENTIC"`，由模型动态检查时间线、画面和音轨。无需切换到 Interactions API；中转需透传这个 Gemini 原生字段。视频仍通过 `inline_data` 发送，受现有中转请求体大小限制。可显式设置 `SOP_VIDEO_ANALYSIS_MODE=static` 使用旧版完整视频单次分析，或设置 `SOP_VIDEO_ANALYSIS_MODE=frames` 通过兼容图像接口使用无音轨抽帧模式。文字改写在兼容网关模式下继续使用 `/v1/chat/completions`。

Agentic 模式在原有 `generateContent` 请求内传输 Base64 视频；视频超过兼容渠道的内联请求上限时会失败。抽帧模式不分析音轨，结果会明确标记。分析模式与是否提交音轨会保存到项目和导出清单。

在 `.env` 配置 Gemini API Key 和可选兼容网关，或在页面「模型连接」设置中输入对应密钥与地址。页面输入的密钥只保留在服务器进程内存；不写入浏览器存储、项目记录或导出包。`.env.example` 是配置模板。模型固定为 **`gemini-3.8-flash`**，不静默替换为其他版本。点击分析时，视频及产品图会发送给当前配置的模型服务商。

当前未配置密钥时，可以创建明确标注的手写示例项目体验编辑和导出；真实分析接口会返回未配置错误，不伪造结果。

## V1 功能

- 一条参考视频：MP4 / MOV / WebM，最大 250 MB、最长 10 分钟；保留音轨，读取真实时长及分辨率，生成本地封面。上传视频 ≥8 MB（8 × 1024 × 1024 字节）时，服务端使用 `ffmpeg-static` 自带的 FFmpeg 压缩为 H.264/AAC MP4（CRF 27、fast、音频 128k），保存实际压缩后的大小、格式与封面；结果未变小时保留上传文件，失败时提示重试并清理临时文件。8 MB 是触发阈值，不保证输出小于 8 MB；读取视频及其他制作步骤仍使用系统 FFmpeg / ffprobe。
- 最多 3 张产品参考图：JPEG / PNG / WebP，每张最大 10 MB，服务端识别实际文件格式。
- Gemini 分析：分镜时间段、作用、画面、动作、口播、画面文字、声音、商品展示及不确定项。
- 模型设置支持 Google 官方 Gemini API，也支持填写网关 API Base URL；视频走 Gemini 原生输入，结果由本地 Schema 和时间轴校验。
- 拆解按一镜头一行展示：从原片截取可播放、可下载的 MP4，保留原声；每镜头提取 1–3 张可放大、下载的关键帧，标明原片绝对时间和选帧依据。Gemini 新分析补充主体外观、动作、运镜、动效、转场/分段依据、英文重建 Prompt 和建议证据时间点。媒体由本机 FFmpeg 按可见行准备并缓存，不追加模型调用；旧分析也可按现有时间线补齐媒体，未记录的字段保持明确标注。编辑镜头边界后切片和关键帧按新区间生成，步骤视图与画布预览共享镜头行。
- 原片对照与编辑：点击镜头定位播放；编辑时间、文本、动作；拆分镜头。保存前校验时间不重叠、不越界。
- 本地化：7 个目标市场与对应语言、TikTok / Reels / Shorts 创意设置、站内商品卡或独立站路径、用户提供的售价币种与优惠、人物/时长/画幅/字幕设置。
- 产品事实作为改写依据；参考片里的功效、优惠和购买路径不会自动变成目标产品事实。不根据市场自动换算价格。
- 输出 3 个开头方向、完整分镜、局部生成指令、全片视觉指令及负面约束。可选择开头并继续编辑。
- Veo 3.1 生产单元：分析分镜保留原片的细粒度剪辑节奏，但不会逐镜头各生成 8 秒。交付页按最终时间线拆成最多 8 秒的生产单元，分别使用 t2v / i2v / r2v 对应模型。每个请求固定输出 8 秒源片；末段按生成计划裁切，再由后期按时间线组装。导出包包含 `06-veo-production-plan.json`，记录每个单元的最终使用区间与来源分镜。
- 交付页提供两种可保存到项目的成片模式。**Veo 原生**保留旧行为：台词、音频和画面文字都写进可编辑 Veo Prompt，由 Veo 尝试生成。**本地配音与字幕**使用另一份可编辑的纯画面 Prompt；完整台词由本机 TTS 生成，按整条视频统一排布，可跨镜头及 8 秒单元连续播放，必要时最多轻微加速 15%。口播字幕与 SRT 跟随实际声音时间，画面文字仍跟随镜头。单元预览按相同时间线截取，可能从一句话中间开始；最终 MP4 保留完整台词。配音在本机 `data/tts-cache/` 缓存，改变文字或音色才生成新的音频。整条视频放不下时，只提示一次是否延长成片，确认后停留末尾画面到口播结束，复用已有源片，不改写台词也不重新提交 Veo。所有源片完成后自动合成，亦可手动重新合成。此模式移除 Veo 原音轨，不需要额外的 TTS Key。
- 交付页的「制作过程画布」一次聚焦一个 8 秒生产单元；每个输入端口明确指向上游节点的输出端口，输出端口列出下游去向。点击端口可查看和复制完整内容，包括 Gemini 请求、分镜、默认/实际 Prompt、第三方请求体及本地配音字幕合成记录。可切换模式与历史生成记录。新任务保存不含 API Key/媒体 base64 的请求与合成快照；旧任务缺失的细节标记为当前数据推导或未留存，不冒充历史网络请求。
- ZIP 包：创意简报 Markdown、Seedance 提示词 TXT、分镜 JSON、原片分析 JSON、项目 manifest、可选 SRT 草稿、已上传的产品图。也支持复制和单独下载提示词。
- 项目与素材保存到 `data/`；草稿自动保存；任务进度持久化；服务重启后中断任务标记失败；修改产品/市场/原片分析后旧改写标记为待更新，阻止误导出。

## 技术结构

- `src/`：React + TypeScript，Linear-inspired 深色工作台；Lucide 图标；响应式 CSS。
- `shared/domain.ts`：共享类型、Zod schema、市场与平台策略、时间线校验。
- `shared/export.ts`：根据最新编辑生成提示词、Markdown、JSON 和 SRT。
- `server/index.ts`：Express API、上传、任务管理、文件打包与同源本机访问限制。
- `server/gemini.ts`：Gemini 原生 `generateContent` 视频与结构化输出，固定 `gemini-3.8-flash`。每次调用最大输出 24,000 tokens，不自动反复重试计费任务。
- `server/veo.ts`：区分三种 Veo 3.1 请求、校验公网图片 URL、提交异步任务、轮询状态并下载成片，由本地 FFmpeg 校验媒体。
- `server/compose.ts` 与 `server/render-captions.swift`：本机配音、文字图层、分镜时间对齐、MP4 合成与 SRT 导出。
- `server/store.ts`：原子 JSON 文件写入、版本冲突检测；适合单进程本机 V1。
- `docs/product-v1.md`：产品边界、行业研究及验收范围。

`SOP_PORT` 可更改端口，`SOP_DATA_DIR` 可更改本地数据目录。更换或移除素材时只移除项目引用，旧原文件保留在 `data/uploads/` 便于恢复。数据目录不提交到 Git。

## 验证与边界

```sh
npm run build
npm run smoke
```

Smoke 检查使用独立临时目录和临时端口，验证项目持久化、视频/图片上传、错误边界、草稿编辑、旧方案失效和 ZIP/SRT 内容，不调用收费模型。

两种成片方式都支持多单元拼接和完整成片下载：Veo 原生模式保留原音轨，本机配音与字幕模式按分镜重新制作配音和文字。系统音色由本机安装决定，人物口型不会自动与后期配音同步。此版不包含自动发布、投放、真实销售看板、团队账户或公网生产部署。Seedance 仍是输出提示词的目标，不代表已接通 Seedance API。

接入真实密钥后的多模态准确率、额度及响应速度需用实际账户与素材验证。UI 浏览器检查未自动运行，遵循用户不使用 browser/computer automation 的要求。

原有 `ai-overseas-tool-functions.html` 与 `assets/ai-overseas-tool/` 作为原始功能资料保留。
